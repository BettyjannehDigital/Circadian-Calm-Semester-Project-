# Circadian Calm – Semester Project

**Semester Project | Noroff Digital Marketing | March 2026**  
**Grade: C (D on first submission, improved)**

---

## Overview

Circadian Calm is a fictional educational wellness brand created for the Noroff Digital Marketing semester project. The brief required building a live content hub targeting a specific audience, demonstrating strategy, content creation, SEO, usability, and accessibility.

The concept was inspired by real professional experience — as a night shift care assistant, I built a resource I genuinely wished existed: structured, research-informed sleep and recovery guidance for shift workers.

The site was built on WordPress and hosted at: [oneohonejewelry.com/circadian-calm](https://www.oneohonejewelry.com/circadian-calm/)

## Content Created (Live on WordPress)

1. **Blog Post** — "How to Sleep After a Night Shift" — research-informed 6-step recovery guide
2. **Landing Page** — "Night Shift Reset Checklist" — lead generation page with email capture
3. **Email Sign-Up Form** — GDPR-compliant consent-based form embedded in landing page
4. **FAQ Page** — Bonus content supporting usability and accessibility

---

## Key Skills Demonstrated

- **Strategy** — Target audience analysis, buyer persona, competitor landscape, brand identity, SMART goal
- **WordPress Development** — Built from scratch: pages, navigation, templates, custom structure
- **SEO** — RankMath optimisation: homepage SEO score improved from 22/100 → 88/100
- **Accessibility** — WAVE audit: AIM score 6.7/10, identified and documented improvements
- **Performance Testing** — One.com Performance Monitor: Accessibility 95, Best Practices 79
- **Content Writing** — Research-backed blog post with Harvard-referenced academic sources
- **Ethical Compliance** — Privacy policy, GDPR-compliant email capture, no medical advice disclaimer
